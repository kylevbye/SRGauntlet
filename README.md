## Project Description
Undertale is one of the most influential games within the Japanese Role-Playing Game (J-RPG) genre. While known for its masterful execution of its story, music, and atmosphere, it unintentionally gained fame in the speedrunning community due to a few oversights made in the game’s design. The most influential oversight is the punch card interaction, which allows players to regain movement at any point, even in scenarios where the player’s movement is supposed to be restricted. The Punch Card Exploit (PCE) can be abused to skip many cutscenes and battles resulting in the game’s any % speedrun category being completable in under an hour.

Developed by 1 person, Project Gauntlet is its own short J-RPG world that is distinct from Undertale, which is designed for RPG speedrunners. It features typical J-RPG elements like enemy encounters, multiple rooms, and a boss fight. On the user’s end, the player’s main goal is to complete the game within the shortest amount of time possible. What makes this project different from other J-RPG is that it features Undertale’s glitches and exploits purposely implemented for players to utlize when trying to achieve competitive completion times.

One of the main issues of Undertale’s current any% speedrun today is that it has become incredibly difficult to achieve a satisfying competitive completion time. Because of this, it becomes intimidating to learn for new runners. Gauntlet looks to provide the Undertale glitched experience in a significantly shorter condensed format. With a shorter experience, this helps ease new runners into learning and mastering Undertale glitches and exploits with the hope that they will be more confident in learning Undertale’s full any% category.
